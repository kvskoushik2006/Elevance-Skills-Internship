# 🤖 Sentiment Analysis Chatbot

## 📌 Project Overview

The Sentiment Analysis Chatbot is a Python-based chatbot that analyzes the emotional tone of user messages and classifies them into three sentiment categories:

- 😊 Positive
- 😐 Neutral
- 😟 Negative

Based on the detected sentiment, the chatbot generates an appropriate response.

The project uses VADER (Valence Aware Dictionary and sEntiment Reasoner) for sentiment analysis and Streamlit for the interactive web interface.

---

## 🎯 Objectives

- Analyze the sentiment of user messages.
- Classify messages as Positive, Negative, or Neutral.
- Provide appropriate chatbot responses based on detected sentiment.
- Develop an interactive chatbot interface using Streamlit.
- Demonstrate practical use of Natural Language Processing for emotion-aware communication.

---

## 🛠️ Technologies Used

- Python
- Streamlit
- VADER Sentiment Analysis
- Natural Language Processing (NLP)
