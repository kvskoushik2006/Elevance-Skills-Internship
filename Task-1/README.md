# AI Chatbot with Knowledge Base

## 📖 Project Overview

This project is an AI-powered chatbot developed using Python that combines intent classification with a knowledge base search. It can answer predefined questions and retrieve relevant information from stored documents, providing intelligent and context-aware responses.

---

## 🚀 Features

- Intent Classification using TensorFlow/Keras
- Knowledge Base Search using FAISS
- Semantic Search with Sentence Transformers
- Dynamic Knowledge Base Update
- User-Friendly Chat Interface
- Fast and Accurate Responses

---

## 🛠 Technologies Used

- Python
- TensorFlow
- Keras
- NLTK
- NumPy
- FAISS
- Sentence Transformers

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/kvskoushik2006/AI-Chatbot-with-Knowledge-Base.git
```

### 2. Install the required libraries

```bash
pip install -r requirements.txt
```

### 3. Run the chatbot

```bash
python main.py
```
